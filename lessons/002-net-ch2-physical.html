物理层：比特如何变成信号，信道的极限在哪里

上一章你看到五层模型的最底层叫「物理层」，任务是「把比特变成信号在线路上传」。这一章解决三个实际问题： ① 比特和信号之间怎么互相转换（编码调制）？② 一条信道最快能跑多快（两个极限公式）？ ③ 一条线路上怎么同时跑多路信号（复用）？照例，我们从场景开始。

一、比特是抽象的，信号是物理的

场景：网卡发出去的到底「长什么样」

上一章说数据链路层交给物理层的是「比特流」——10110010……但比特本身是抽象的信息， 看不见摸不着。物理层的真正工作是：用电压高低、光的明暗、无线电的波形这些物理量来表示 0 和 1。 这些携带数据的、随时间变化的物理量，就是信号（signal）。

于是有了一条完整的发送链路（数据通信系统模型，必考）：

源系统（发送方：源点 → 发送器）→ 传输系统（信号在线路中传播）→ 目的系统（接收方：接收器 → 终点）

其中源点产生比特流（比如你的电脑），发送器把比特编码成信号（你的网卡、调制解调器）， 接收器把信号还原成比特。术语约定：数据是运送信息的实体（比特），信号是数据的电气或电磁表现； 而信号的最小单位单位叫码元（symbol）——固定时长的信号波形。

码元是本章最重要的前置概念：一个码元 = 一个固定时长的信号脉冲。最简单的方案是一个码元表示 1 个比特（高电平=1，低电平=0）； 但一个码元也可以携带更多信息——比如让码元的振幅取 4 种值（00、01、10、11 各对应一种）， 每个码元就能携带 2 比特。码元状态数 n 与比特数的关系：每码元携带 log₂n 比特。 记住它，两个极限公式全靠它。

模拟信号与数字信号

模拟信号：取值连续（正弦波，像声波）；数字信号：取值离散（方波，只有高低两种电平）。 计算机内部产生的是数字信号（基带信号，原始的 0/1 电平脉冲）。 但很多既有线路只能传模拟信号——典型场景：老式电话线是为人声（300~3400 Hz）设计的， 数字脉冲直接上去会被滤得不成样子。怎么办？调制：让数字信号「骑」在正弦载波上。 三种基本调制方法（必考）：调幅 ASK（用振幅变化表示 0/1）、调频 FSK（用频率变化）、调相 PSK（用相位变化）。 解调是逆过程。既能调又能解的设备就是调制解调器（modem，俗称「猫」）。

二、信道的极限：两个公式决定一切（全章考点之王）

场景：为什么网线不能无限快

厂商天天宣传更快更快的网卡，但物理规律决定了任何信道都有天花板。给出天花板的，是两个公式。

1. 奈氏准则：无噪声信道的波特率极限

1924 年奈奎斯特发现：在理想、无噪声的低通信道中，为避免码元之间互相干扰（码间串扰）， 极限传输速率是 2W Baud（W 是信道带宽，单位 Hz；Baud 即波特，每秒传输的码元数）。

注意它的两个关键点：① 它限制的是码元速率（波特率），不是比特率； ② 如果想提高比特率，出路是让每个码元携带更多比特（提高调制级数 n）。 所以理想信道的极限比特速率 = 2W·log₂n bit/s。但 n 不能无限增大——真实信道永远有噪声， 码元携带的比特越多，每个状态的区分就越精细，噪声一干扰就分不清了。于是第二个公式登场。

2. 香农公式：有噪声信道的速率极限

1948 年香农给出更普适的结论：C = W·log₂(1 + S/N)，其中 C 是极限比特速率（信道容量）， S/N 是信号功率与噪声功率之比。信噪比常用分贝（dB）表示：信噪比(dB) = 10·log₁₀(S/N)—— 反过来换算：30 dB 意味着 S/N = 10³。

香农公式的深刻之处：① 噪声决定上限，提高信噪比或带宽才能提高极限，跟怎么调制无关； ② 速率低于 C 时可以做到无差错传输（理论层面）。两个公式联合使用： 理想信道看奈氏，有噪声信道看香农，实际可达速率取两者中较小值。

计算题标准流程（每年必考题型）：① 有噪声 → 先把 dB 换算成 S/N（S/N = 10^(dB/10)）→ 套香农公式求 C； ② 问「每码元最多携带多少比特」→ 用香农的 C 除以奈氏的 2W，取 log₂。 例题：带宽 3 kHz、信噪比 30 dB 的信道，C = 3000·log₂(1+1000) ≈ 3000 × 9.97 ≈ 30 kbit/s； 极限波特率 2W = 6000 Baud → 每码元至少携带 30000/6000 = 5 bit 信息（取 log₂32 = 5，即至少 32 级调制）。

三、编码：把比特画成波形

回到网卡：它怎么把 10110010 变成电平？这就是编码。三种教科书必考的基带编码方式：

  • 不归零制（NRZ）：1 整个码元期高电平，0 低电平。最简单，但连续多个 1（或 0）时线上是「一条直线」—— 接收方无法判断每个码元的边界（时钟同步困难），且平均有直流分量。
  • 曼彻斯特编码：每个码元中间必有一次电平跳变——这个跳变既当数据（向上跳/向下跳表示 0/1）又当时钟（帮接收方对齐码元边界）， 一举两得。代价：每个码元两次电平变化，编码效率只有 50%（10 Mb/s 以太网要 20 MBaud 的波特率）。 注意不同文献对「跳变方向表示 0 还是 1」约定相反，考试以你的教材为准——下面绘制器采用前半高后半低 = 1。
  • 差分曼彻斯特编码：数据不在跳变方向里，而在码元开始处有没有跳变—— 开始处有跳变 = 0，无跳变 = 1（谢希仁教材约定）。看「变化」而不是「绝对电平」，抗极性接反等干扰更稳。
判波形题是画图/选择双考：拿到一段波形要能反推编码类型。要点：NRZ 无中间跳变；曼彻斯特每个码元中间都有跳变；差分曼彻斯特也是每码元中间有跳变（它是曼彻斯特的变体），区别看开始处。效率考点：曼彻斯特/差分曼彻斯特都是 50%。

四、传输媒体：信号的「跑道」

信号总得有个载体。分两大类（简答题常考「各自特点」）：

导引型媒体（有线）

  • 双绞线：两根绝缘铜线绞合——绞合是为了互相抵消电磁干扰。无屏蔽的叫 UTP（家用网线）， 带金属屏蔽层的叫 STP。按质量分级（CAT5e、CAT6……），家用以太网主流，便宜、易安装、距离一般 ≤ 100 m。
  • 同轴电缆：内芯 + 网状屏蔽层，抗干扰强于双绞线，早期用于电视与局域网（50Ω 细缆），现多见于有线电视（75Ω）。
  • 光缆（光纤）：利用光的全反射传输光脉冲——光从光密介质射向光疏介质且入射角足够大时全部反射回介质内， 信号被锁在纤芯里。分两种：多模光纤（纤芯粗，多条光线角度不同并行前进，易色散，适合近距离，便宜）； 单模光纤（芯径细到与波长同量级，光几乎直线传播不反射，耗损小、适合远距离骨干网，需激光源，较贵）。

非导引型媒体（无线）

短波（电离层反射，质量不稳）、微波（直线传播，地面接力/卫星）、红外。微波是无线通信的主力， 注意其直线传播特性决定了基站必须「视线可达」或密集部署。

🔬 动手实验：查看你的网卡

ipconfig /all

找到你的有线/无线网卡条目：① 「描述」是网卡型号；② 「物理地址」（形如 XX-XX-XX-XX-XX-XX）是网卡的 MAC 地址——它是第3章数据链路层的地址，现在先混个眼熟；③ 无线网卡条目里的「接收/传输速率」 （如 866/866 Mbps）就是当前 Wi-Fi 的协商速率；④ 「默认网关」是数据离开你家网络的下一跳路由器地址。 把网卡速率 ÷ 8，对比你家宽带的标称带宽，看看哪个环节才是瓶颈。

五、信道复用：一条路怎么让多人同时用

场景：一条骨干光纤的带宽是单用户的几十倍，铺一条线只给一个人用太浪费。 复用就是「多路信号合用一条信道」的技术。类比高速路：不同车道 = 不同用户。

  • 频分复用 FDM：把信道带宽按频率切分，每路信号占一个子频段，所有用户同时占不同频带。 所有用户独占「频带」、共享「时间」。模拟时代的经典方案，电话中继线靠它一线上千路通话。
  • 时分复用 TDM：把时间切成周期性的时隙轮换分配——每个用户独占「时间片」、共享「频率」。 问题：某用户没有数据时它的时隙照样空转浪费。
  • 统计时分复用 STDM：改进版——时隙按需分配，有数据才占，通过「集中器」实现。 线路利用率更高，但用户数据可能排队，时延不固定。
  • 波分复用 WDM：光的频分复用——一根光纤同时传多个不同波长的光载波，骨干网扩容的主力。
  • 码分复用 CDM / 码分多址 CDMA：最巧妙——所有用户同时、同频通信，每人分配一个独特的「码片序列」 （如 8 位 ±1 序列），发送时把数据比特展开成码片，接收端用同一序列做内积即可分离出目标用户的数据 （不同站码片序列相互正交：内积为 0）。手机 3G 时代的 CDMA 技术基础。
复用辨析题：「谁独占频带、谁独占时隙」——FDM 各用户独占频带共享时间；TDM 各用户独占时隙共享频带； CDMA 全部共享（靠码片正交区分）。STDM 相比 TDM 的改进点是「按需分配时隙」。

六、家庭宽带接入：把这一章串起来

最后看两个真实技术如何综合运用本章知识：ADSL（电话线上网）——用频分复用把电话线分成 「0~4kHz 电话 + 更高频段上行 + 更高频段下行」三段，电话上网互不干扰（所以叫非对称 DSL：下行远快于上行）； FTTx（光纤接入）——光纤到路边 FTTB / 到户 FTTH，配合无源光网络分光器让多户共享一根光纤（又一次复用）。 你家的宽带正是这两个公式 + 复用技术的商业产物。
