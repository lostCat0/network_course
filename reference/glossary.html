计算机网络术语表

随章节持续扩充 · 术语与谢希仁《计算机网络》保持一致

第1章 概述

主机 / 端系统
位于网络边缘、可直接接入互联网的设备（电脑、手机、服务器）。
网络的核心部分 / 边缘部分
边缘 = 大量端系统；核心 = 由路由器、链路组成的网格，负责数据的存储转发与搬运。
电路交换
通信前建立连接、资源独占、结束后释放。实时性强，线路利用率低。三步：建立→传输→释放。
存储转发
节点收到完整数据块后才向下一节点转发，是报文/分组交换的基础机制。
报文 / 分组
报文 = 完整的数据块；分组 = 报文切分后的较小数据块 + 首部（含目的地址等控制信息）。
分组交换
报文切成较短的分组并加首部，按存储转发逐跳传输；可流水线化；代价是首部开销、可能丢包乱序。总时延 ≈ (x + (k−1)p)/b。
发送时延 / 传播时延
发送时延 = 数据长度 ÷ 发送速率（机器吐比特的时间）；传播时延 = 信道长度 ÷ 传播速率（比特在链路上飞的时间）。二者性质完全不同。
时延带宽积
传播时延 × 带宽，即链路上容纳的比特总量（管道容积）。
利用率与时延
D = D₀/(1−U)：信道利用率 U 接近 1 时时延趋于无穷，故实际网络不做满负荷设计。
协议三要素
语法（格式结构）、语义（动作含义）、同步（事件顺序）。
五层数据单元
物理层比特 → 链路层帧 → 网络层分组 → 运输层报文段（TCP）/用户数据报（UDP）→ 应用层报文。

第2章 物理层

信号 / 码元
信号 = 数据的电气或电磁表现；码元 = 固定时长的信号波形，每个码元可携带 log₂n 比特（n 为离散状态数）。
基带信号 / 带通信号
原始的数字 0/1 电平脉冲 / 经调制「骑」在载波上的模拟信号。
调制三法
调幅 ASK（振幅）、调频 FSK（频率）、调相 PSK（相位）；能调能解的设备叫调制解调器（modem）。
奈氏准则
理想无噪声信道极限波特率 = 2W Baud（W 为带宽 Hz）；提高比特率需增大调制级数 n。
香农公式
C = W·log₂(1+S/N)，有噪声信道的极限比特速率；信噪比(dB) = 10·log₁₀(S/N)。实际速率取奈氏与香农的较小值。
不归零制 NRZ
1 全程高电平、0 全程低电平；连续同值时无跳变，难以同步时钟，有直流分量。
曼彻斯特编码
每码元中间必有一次电平跳变，兼具数据与时钟；编码效率 50%。
差分曼彻斯特编码
看码元开始处：有跳变 = 0，无跳变 = 1（谢希仁约定）；抗极性干扰。
多模 / 单模光纤
多模：芯粗、多光束并行、易色散、近距离便宜；单模：芯细、直线传播、耗损小、远距离骨干。
FDM / TDM / STDM
频分（独占频带共享时间）/ 时分（独占时隙共享频带）/ 统计时分（按需分配时隙）。
CDMA
码分多址：各站用相互正交的码片序列同时同频通信，接收端内积分离。

第3章 数据链路层

封装成帧
数据前后加首尾部构成帧，用于定界并承载控制信息。
透明传输
无论数据内容是什么都能原样通过链路层；字节填充（PPP）或比特填充（HDLC）防止数据中出现的定界符被误判。
CRC 循环冗余检验
模 2 除法算出冗余码 FCS 拼在数据后；只能检错不能纠错，补 0 个数 = 多项式最高次数。
PPP 协议
点对点链路协议：封装方法 + LCP（链路控制）+ NCP（网络控制，如分配 IP）；无序号无确认，可靠传输交给 TCP。
CSMA/CD
载波侦听多点接入/冲突检测：先听后发、边发边听、冲突停发、随机退避（二进制指数退避）。
争用期 2τ
信号最坏往返时延；帧的发送时延必须 ≥ 2τ 才能保证冲突可检测 → 10M 以太网最短帧长 64 字节。
MAC 地址
48 位硬件地址，标识链路上的一块网卡；帧每过一跳就更换，IP 地址端到端不变。
以太网 V2 帧格式
目的 MAC 6B + 源 MAC 6B + 类型 2B（0x0800 IP / 0x0806 ARP）+ 数据 46~1500B + FCS 4B。
交换机自学习
收到帧时记录「源 MAC→入端口」，查不到目的 MAC 则泛洪；逐渐建成 MAC 地址表，每端口独立碰撞域。
碰撞域 vs 广播域
集线器不隔离碰撞域；交换机隔离碰撞域不隔离广播域；路由器两者都隔离。
VLAN
802.1Q 在帧中插 4B 标签，把交换机端口划入逻辑广播域；跨 VLAN 互通需三层设备。

第4章 网络层

尽最大努力交付
网络层不保证不丢、不按序、不时限；把可靠传输留给端系统，核心保持简单高速。
IPv4 首部关键字段
首部长度单位 4 字节、总长度单位字节；TTL 每跳减 1；协议字段 1=ICMP 6=TCP 17=UDP；首部校验和只校验首部。
CIDR 无分类编址
「IP/前缀长度」表示任意大小网络；计算三板斧：掩码→按位与求网络地址→主机位全 1 得广播地址；可用主机 = 2^主机位−2。
最长前缀匹配
目的 IP 命中多条路由时选前缀最长（最具体）的一条。
ARP 地址解析协议
同网段由 IP 找 MAC：广播请求 + 单播应答 + 双方缓存；跨网段时 ARP 问的是网关（下一跳）。
ICMP
依附 IP 的差错与询问报文；Echo 请求 8/应答 0（ping）、超时 11、终点不可达 3；tracert 靠 TTL 递增 + 超时/应答报文逐跳测绘。
RIP / OSPF / BGP
距离向量传整表（跳数≤15）/ 链路状态传拓扑（Dijkstra 最短路）/ 路径向量管 AS 间策略路由。
静态路由
手工配置「目的网段 → 下一跳」；数据通信必须双向都配（去程 + 回程）。

第5章 运输层

端口 / 套接字
16 位进程门牌号（熟知 0~1023 / 短暂 49152~65535）；套接字 = IP:端口，TCP 连接由一对套接字唯一标识。
UDP 特点
无连接、尽最大努力、面向报文、首部 8 字节、无拥塞控制——适合实时音视频与 DNS。
面向字节流
TCP 把数据视为无边界的字节流自行分块，「粘包」根源在应用层需自定义边界。
三次握手
SYN → SYN+ACK（合并是只需三次的原因）→ ACK；防失效连接请求突然到达造成资源浪费。
四次挥手与 2MSL
全双工两方向独立关闭，ACK 与 FIN 不能合并；主动方等 2MSL 保证最后 ACK 可重传并让旧报文消亡。
滑动窗口 / 累积确认 / SACK
连续 ARQ 提高效率；确认号指「这之前的都收到」；SACK 选择确认补齐中间丢段（真实抓包中 SLE/SRE 标志）。
流量控制 vs 拥塞控制
怕接收方爆缓存（rwnd）vs 怕网络爆路由器（cwnd）；实际发送窗口 = min(rwnd, cwnd)。
拥塞控制四算法
慢开始（每 RTT 翻倍）→ 拥塞避免（+1）；超时则 ssthresh 减半、cwnd 回 1；3 个重复 ACK 触发快重传 + 快恢复（cwnd=ssthresh 不回 1）。

第6章 应用层

DNS 层次域名系统
根→顶级域→权威服务器分权管理；主机→本地服务器递归查询，本地→各级迭代查询；缓存 + TTL。
DNS 记录类型
A（IPv4）、AAAA（IPv6）、CNAME（别名）、MX（邮件）；常规查询 UDP 53。
HTTP 特点
无状态、基于 TCP、灵活传任意内容；状态码 2xx 成功 3xx 重定向 4xx 客户端错 5xx 服务器错。
持久连接
HTTP/1.1 一次握手复用多条请求；非持久每个对象 2×RTT，计算题常考对比。
HTTPS
HTTP over TLS（443 端口），内容加密——抓包只见「Application Data」。
DHCP 四步曲 DORA
Discover 广播 → Offer → Request 广播（通知落选者）→ Ack；UDP 67/68，自动下发 IP/掩码/网关/DNS 四件套。
FTP 双连接
21 控制连接 + 20 数据连接，控制信息带外传送。
邮件协议组合
全程「推-推-拉」：发件人 —SMTP→ 发方服务器 —SMTP→ 收方服务器 —POP3/IMAP→ 收件人。
P2P vs C/S
C/S 服务器是瓶颈；P2P 每节点既是客户又是服务器，用户越多能力越强（自扩展）。
